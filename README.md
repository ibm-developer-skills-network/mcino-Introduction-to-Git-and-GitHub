# Introduction to Git and GitHub

## Simple Interest Calculator

### Project Description

The **Simple Interest Calculator** is a basic calculator that calculates the simple interest on a given principal amount. The calculation uses the **principal amount**, **annual interest rate**, and **time period in years**.

This project is designed to demonstrate basic programming concepts as well as the use of **Git and GitHub** for managing and sharing source code.

### Inputs

The calculator requires the following three inputs:

- **p** — Principal amount (the initial amount of money)
- **t** — Time period in years
- **r** — Annual rate of interest

### Formula

The simple interest is calculated using the following formula:

**Simple Interest = p × t × r**

Where:

- **p** = Principal amount
- **t** = Time period in years
- **r** = Annual interest rate

### Example

If:

- Principal amount = 1,000
- Time = 2 years
- Interest rate = 5%

Then:

**Simple Interest = 1000 × 2 × 0.05 = 100**

Therefore, the simple interest is **100**.

### Output

The calculator displays the calculated **simple interest** based on the values provided by the user.
