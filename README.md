# Simple Interest Calculator

## Project Description
A simple command-line calculator tool built using Bash scripting to calculate simple interest based on user-provided values.

## Features
- Enter principal amount.
- Enter annual rate of interest.
- Enter time period in years.
- Calculate simple interest instantly.
- Display the total amount.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

## Technologies Used
- Bash
- Git
- GitHub

## How to Run
1. Clone this repository.
2. Open the terminal.
3. Navigate to the project directory.
4. Run `bash simple-interest.sh`.
5. Enter the requested values.
