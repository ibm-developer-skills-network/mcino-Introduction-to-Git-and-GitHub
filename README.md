# Simple Interest Calculator

**Project name:** Simple Interest Calculator

A small command-line project written in Bash. It asks the user for a principal
amount, an annual rate of interest and a time period in years, and prints the
simple interest for those values.

## Project details

## Formula

```
Simple Interest = (Principal x Rate x Time) / 100
```

```
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output:
   simple interest = (p * t * r) / 100
```

## How to run

```bash
bash simple-interest.sh
```

The script then asks for three inputs:

1. **Principal** — the amount of money that was borrowed or invested
2. **Rate of interest** — the annual rate, entered as a percentage
3. **Time period** — the number of years

## Example

```
Enter the principal:
1000
Enter rate of interest per year:
5
Enter time period in years:
2
The simple interest is:
100
```
