# Simple Interest Calculator

## Project Description

This project is a simple interest calculator that calculates the simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal: The initial amount of money.
- Rate: The annual rate of interest.
- Time: The time period in years.

## Output

The calculator displays the simple interest calculated using the provided inputs.
