# Simple Interest Calculator

A simple Bash-based command-line tool that calculates simple interest based on user-provided principal amount, rate of interest, and time period.

## Features
- Takes principal, rate of interest, and time as input
- Calculates simple interest using the formula: SI = (P x R x T) / 100
- Displays the result to the user

## Usage
```bash
./simple-interest.sh
```
