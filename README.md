# Simple Interest Calculator

A Bash script designed to calculate simple interest based on user inputs.

## Purpose
This script calculates the simple interest accrued over a period of time given the principal amount, annual interest rate, and time period in years.

## Formula
$$\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$

## Inputs
- **Principal**: The initial sum of money deposited or borrowed.
- **Rate**: The annual interest rate (in percentage).
- **Time**: The time duration in years.

## Usage
Run the script using Bash:
```bash
./simple-interest.sh
