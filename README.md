# Simple Interest Calculator

## Project Overview
This project is a simple Bash script that calculates simple interest based on user input. It is part of the Introduction to Git and GitHub final project on Coursera/IBM Skills Network.

## Features
- Takes user input for:
  - Principal amount
  - Rate of interest
  - Time period
- Calculates simple interest using the formula:
  
  **Simple Interest = (Principal × Rate × Time) / 100**

- Displays the result to the user.

## How to Run
1. Clone this repository.
2. Navigate to the project directory.
3. Run the script:
```bash
   bash simple-interest.sh
```
4. Enter the principal, rate, and time when prompted.
