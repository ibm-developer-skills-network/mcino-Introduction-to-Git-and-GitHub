## Simple Interest Calculator

A calculator that computes simple interest based on the principal amount, annual interest rate, and time period in years.

```
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output
   simple interest = p*t*r
```


## Usage

Run the simple interest calculator using Bash:

```bash
bash simple-interest.sh
```

The calculator uses the principal amount, annual interest rate, and time period to calculate simple interest.
