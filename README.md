## Simple Interest Calculator

This project contains a Bash script that calculates simple interest based on the user's input.

### Formula

Simple interest is calculated using:

**I = P × R × T**

Where:

* **P** = Principal amount
* **R** = Annual rate of interest
* **T** = Time period in years
* **I** = Simple interest

### How It Works

The calculator asks the user to enter:

1. Principal amount
2. Annual rate of interest
3. Time period in years

It then calculates and displays the simple interest.

### Example

For a principal of **1000**, an annual interest rate of **5%**, and a time period of **2 years**:

**Simple Interest = 1000 × 0.05 × 2 = 100**

### How to Run

Run the Bash script from the terminal:

```bash
./simple-interest.sh
```

The script will prompt you to enter the principal amount, rate of interest, and time period.

### Input

* Principal amount
* Annual rate of interest
* Time period in years

### Output

The calculated simple interest based on the values entered by the user.
