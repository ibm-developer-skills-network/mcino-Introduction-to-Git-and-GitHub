# Introduction to Git and GitHub

## Simple Interest Calculator

A calculator that calculates simple interest given the principal amount, annual
rate of interest, and time period in years by Jahnvi Vyas.

This project demonstrates a simple shell script that calculates simple interest
using the standard mathematical formula. It is designed for learning basic Git
and GitHub concepts, including version control, collaboration, and repository
management.

```
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output
   simple interest = p*t*r
```
