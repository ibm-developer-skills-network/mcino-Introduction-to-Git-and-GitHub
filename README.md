# Simple Interest Calculator

A simple Bash script that calculates simple interest using the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## How to run

1. Open a terminal in this folder.
2. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

3. Run it:

   ```bash
   ./simple-interest.sh
   ```

4. Enter the principal, rate of interest, and time period when prompted.

## Example

For principal `1000`, rate `5`, and time `2` years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
