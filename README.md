# Calculadora de Interés Simple

Una aplicación web interactiva y sencilla diseñada para calcular el interés simple a partir del capital inicial, la tasa de interés anual y el período de tiempo.

## Descripción

Este proyecto proporciona una herramienta fácil de usar para calcular el interés total acumulado o generado a lo largo de un número determinado de años. La aplicación calcula el interés simple aplicando la fórmula financiera estándar:

$$\text{Interés} = \frac{P \times R \times T}{100}$$

Donde:
* **P** = Capital o monto principal (*Principal*)
* **R** = Tasa de interés anual (%) (*Rate*)
* **T** = Período de tiempo en años (*Time*)

## Características

* **Control deslizante interactivo:** Ajuste dinámico de la tasa de interés mediante un slider en tiempo real.
* **Validación de entradas:** Comprobación para evitar valores negativos o campos vacíos.
* **Cálculo instantáneo:** Despliegue inmediato del monto resultante y el año final estimado sin recargar la página.
* **Interfaz limpia:** Diseño simple, claro y responsivo.

## Tecnologías Utilizadas

* **HTML5:** Estructura semántica del documento y campos de formulario.
* **CSS3:** Estilos visuales y diseño adaptable.
* **JavaScript:** Manipulación del DOM en tiempo real y lógica de cálculo aritmético.

## Instrucciones de Uso

1. Clona o descarga este repositorio en tu equipo local.
2. Abre el archivo `index.html` en cualquier navegador web moderno.
3. Ingresa el monto principal, ajusta el deslizador de tasa de interés, selecciona la cantidad de años y haz clic en **Compute Interest** (o **Calcular Interés**).
