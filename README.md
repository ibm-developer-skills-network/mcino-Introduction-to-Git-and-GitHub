# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest based on user-provided values.

## Features

- Accepts principal amount from the user.
- Accepts annual rate of interest.
- Accepts time period in years.
- Calculates simple interest using the formula:

  **Simple Interest = (Principal × Rate × Time) / 100**

- Displays the calculated simple interest.

## Technologies Used

- Bash Scripting
- Git
- GitHub

## How to Run

1. Clone this repository.
2. Open the terminal in the project directory.
3. Run the script:

   ```bash
   bash simple-interest.sh
   ```

4. Enter the principal, rate of interest, and time period when prompted.
