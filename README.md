
# Simple Interest Calculator

## Project Overview

The Simple Interest Calculator is a Bash-based application that calculates simple interest using three inputs provided by the user: principal amount, annual rate of interest, and time period.

This project demonstrates basic programming concepts, user input handling, arithmetic calculations, and Bash scripting.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal: Initial amount of money.
- Rate: Annual interest rate in percentage.
- Time: Time period in years.

## Features

- Accepts principal amount from the user.
- Accepts annual interest rate.
- Accepts time period in years.
- Calculates simple interest automatically.
- Displays the calculated simple interest.

## Technologies Used

- Bash Shell Scripting
- Git
- GitHub

## How to Run

1. Clone this repository.
2. Open a terminal.
3. Navigate to the project directory.
4. Run the following command:

```bash
bash simple-interest.sh
```

5. Enter the principal amount, rate of interest, and time period when prompted.

## Example

Input:
- Principal: 10000
- Rate: 5
- Time: 2

Output:
- Simple Interest: 1000

## Project Objective

The objective of this project is to learn Bash scripting, Git version control, and GitHub repository management through a practical Simple Interest Calculator.
