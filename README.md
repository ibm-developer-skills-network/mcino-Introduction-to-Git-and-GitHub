# Simple Interest Calculator

A command-line Simple Interest Calculator built with Bash. It prompts the user for a principal amount, rate of interest, and time period, then calculates and displays the simple interest.

## Project Description

This project provides a lightweight Bash script that computes simple interest using the standard formula:

**Simple Interest (SI) = (Principal × Rate × Time) / 100**

It is intended as a learning project for practicing Git and GitHub workflows, including forking, branching, committing, and creating pull requests.

## Features

- Prompts the user for three inputs: principal amount, rate of interest, and time period
- Calculates simple interest using the standard formula
- Displays the calculated interest in a clear, readable format
- Simple, dependency-free Bash implementation

## Getting Started

### Prerequisites

- A Unix-like environment with Bash installed (Linux, macOS, or WSL on Windows)

### Installation

1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate into the project directory:
   ```bash
   cd <repository-name>
   ```
3. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```

### Usage

Run the script from the terminal:

```bash
./simple-interest.sh
```

You will be prompted to enter:
- **Principal amount** — the initial sum of money
- **Rate of interest** — the annual interest rate (as a percentage)
- **Time period** — the duration in years

The script will then display the calculated simple interest.
