# Simple Interest Calculator

A simple Bash-based **Simple Interest Calculator** that computes simple interest from user input.

## Description
This project contains a shell script (`simple-interest.sh`) that asks the user for the following input fields and calculates the simple interest:

- **Principal** (P): the initial amount of money
- **Rate of Interest** (R): the annual interest rate in percent
- **Time Period** (T): the duration in years

## Formula
Simple Interest = (Principal x Rate x Time) / 100

## Usage
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

## Example
```
Enter the principal amount: 1000
Enter the rate of interest (%): 5
Enter the time period (years): 2
Simple Interest = 100.00
```
