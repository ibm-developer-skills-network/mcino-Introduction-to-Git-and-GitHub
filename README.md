# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based calculator that calculates
simple interest using the principal amount, rate of interest, and time period
provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator accepts three inputs:

- Principal amount
- Rate of interest
- Time period

## Output

The program calculates and displays the simple interest based on the values
entered by the user.
