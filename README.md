# Simple Interest Calculator

A simple Bash script to calculate simple interest based on user input.

## Description

This project provides a command-line calculator that computes simple interest
using the following formula:

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Accepts principal amount from the user
- Accepts annual rate of interest
- Accepts time period in years
- Calculates and displays simple interest

## Prerequisites

- Linux, macOS, or Windows with Git Bash
- Bash Shell

## Usage

1. Clone the repository.

```bash
git clone https://github.com/jahnvi-vyas/mcino-Introduction-to-Git-and-GitHub.git
```

2. Navigate to the project.

```bash
cd simple-interest-calculator
```

3. Give execute permission.

```bash
chmod +x simple-interest.sh
```

4. Run the script.

```bash
./simple-interest.sh
```

## Example

```
Simple Interest Calculator

Enter Principal Amount: 10000
Enter Rate of Interest (%): 5
Enter Time (Years): 2

Simple Interest = 1000
Total Amount = 11000
```

## Formula

Simple Interest = (Principal × Rate × Time) / 100
