# Simple Interest Calculator

## Project Description
Simple Interest Calculator is a beginner-friendly Bash command-line program that calculates simple interest using the principal amount, annual rate of interest, and time period in years.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: initial amount
- Rate: annual rate of interest (percentage)
- Time: duration in years

## How to Run
1. Open a terminal in the project directory.
2. Make the script executable: `chmod +x simple-interest.sh`
3. Run it: `./simple-interest.sh`
4. Enter the principal, rate, and time when prompted.

## Example
For principal `1000`, rate `5`, and time `2`, the simple interest is `100.00`.
