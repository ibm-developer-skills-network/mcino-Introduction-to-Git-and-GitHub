# Guía de Contribución

¡Gracias por considerar contribuir a este proyecto!

Se aceptan todas las contribuciones, informes de errores, correcciones de errores, mejoras en la documentación, mejoras y ideas.

## Cómo contribuir

1. **Informar de un error (Bug Report):** Si encuentras un fallo, abre un *Issue* en el repositorio describiendo el problema y los pasos para reproducirlo.
2. **Proponer mejoras o ideas:** Abre un *Issue* para debatir nuevas funcionalidades antes de comenzar el desarrollo.
3. **Enviar cambios (Pull Request):**
   - Realiza un *Fork* del repositorio.
   - Crea una rama para tus cambios (`git checkout -b feature/nueva-mejora`).
   - Confirma tus modificaciones con un mensaje claro (`git commit -m 'Añade nueva funcionalidad'`).
   - Envía tus cambios a tu repositorio remoto (`git push origin feature/nueva-mejora`).
   - Abre un *Pull Request* hacia la rama principal del proyecto original.
