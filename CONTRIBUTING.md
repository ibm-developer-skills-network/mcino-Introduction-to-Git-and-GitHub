# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Contribution Guidelines

1. **Fork the Repository**: Fork this repository to your GitHub account.
2. **Clone the Repository**: Clone your forked repository locally.
   ```bash
   git clone https://github.com/SKYFALLrumbles/mcino-Introduction-to-Git-and-GitHub.git
   ```
3. **Create a Branch**: Create a feature or bug fix branch.
   ```bash
   git checkout -b <branch-name>
   ```
4. **Make Changes and Commit**: Implement your changes and commit with meaningful commit messages.
   ```bash
   git commit -m "Commit message"
   ```
5. **Push and Open a Pull Request**: Push your branch to GitHub and create a Pull Request against the main branch.
