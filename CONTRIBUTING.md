# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute
1. Fork the repository.
2. Create a branch for your change.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Push your branch to your fork.
6. Open a pull request describing your changes.

## Reporting Issues
When reporting a bug, include steps to reproduce it, the expected result, the actual result, and relevant terminal output.

## Code and Documentation
Keep changes focused, use clear names, and update documentation when behavior changes.
