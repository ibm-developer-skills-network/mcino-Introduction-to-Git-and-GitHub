# Simple Interest Calculator

## Project Description
This project is a Bash shell script that calculates simple interest 
based on user input. It is part of the final project for the 
"Introduction to Git and GitHub" course.

## How it Works
The script prompts the user to enter:
- Principal amount
- Rate of interest
- Time period (in years)

It then calculates and displays the simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Usage
```bash
bash simple-interest.sh
```

## Files
- `simple-interest.sh` — Bash script for the simple interest calculator
